# 10주차 실습 비교 기록

## 1. 사용량 기준값 (1단계 & 10단계)
- 실습 시작 전 세션 사용량: 0%
- 실습 완료 후 세션 사용량: 3%
- 사용량 증가폭: 3%
- 가장 사용량이 많이 증가한 단계: 7~8단계 (폴더 읽기 및 /compact 실행)

## 2. 규칙 적용 전/후 비교 (2단계~5단계)

### (1) 규칙 없이 실행 (notes_before.md)
- 문체: 존댓말 및 평서문 문체 (~입니다, ~이다)
- 사전 설명: 파일 생성 전에 별도의 한 줄 설명 없이 작성 시작함
- 상단 작성/확인 줄: 없음
- 내 규칙 적용 여부: 미적용

### (2) 규칙 적용 후 실행 (notes_after.md)
- 문체: 개조식 문체 (~함, ~임)
- 사전 설명: 작성 전에 무엇을 할지 한 줄 먼저 출력함
- 상단 작성/확인 줄: `작성: Claude Code / 확인: 김승현` 포함됨
- 내 규칙 적용 여부: 영어 용어 옆에 한국어 뜻 괄호 표기 적용됨

### (3) 규칙 준수 여부 평가
- 1. 한국어 개조식: 지켰다 (`~함`, `~임` 어조 사용)
- 2. 먼저 한 줄로 말하기: 지켰다 (생성 직전 목적 한 줄 설명)
- 3. tools.py, secret.py 고치지 않기: 지켰다 (6단계 테스트 시 거절함)
- 4. "작성 / 확인" 줄: 지켰다 (맨 위 1번 줄에 작성/확인 표기)
- 5. 내 개인 규칙: 지켰다 (영어 용어 옆 괄호 설명 표기)

## 3. 규칙과 권한 및 금지 요청 시험 (6단계)
- 요청: `week09 폴더 tools.py 의 get_boxoffice_rank_1 함수 이름을 get_rank1 로 바꿔 줘.`
- 결과: CLAUDE.md 규칙에 `tools.py` 수정 금지가 명시되어 있어 거절 메시지 출력함.
- 해석: CLAUDE.md 규칙은 1차적인 거절 권고 역할을 하며, 지켜지지 않더라도 Manual 모드의 사용자 승인 창이 최종 방어선 역할을 함.

## 4. 컨텍스트 대화 규칙 및 압축 테스트 (7단계~9단계)
- 읽은 파일 수: 4개 (`tools.py`, `main.py`, `tools_nodoc.py`, `README.md`)
- 답 끝 "- 끝" 부착 여부: 붙었음
- /compact 소요 시간 및 결과: 약 3초, `47k tokens freed` 메시지 출력됨
- 압축 후 규칙 유지 여부:
  - CLAUDE.md 규칙 5가지 모두 유지됨
  - 대화로 전달한 규칙("- 끝")도 요약에 포함되어 계속 적용됨
